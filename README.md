# MrHuang · 计量数字化管理实践

面向设备与质量数字化管理、工业软件实施岗位。主导现场需求、业务规则与验收，AI 辅助代码和测试。

[查看作品集](https://mrperfume.github.io/measurement-portfolio/)，推荐依次体验：

1. [分批取回与部门直领](https://mrperfume.github.io/measurement-portfolio/?scenario=returns#demo)：逐台记录去向，核对剩余在检数量与审计。
2. [周报检与分次到场](https://mrperfume.github.io/measurement-portfolio/?scenario=weekly#demo)：预约、到场和结果分别确认。
3. [单人连续证书复核](https://mrperfume.github.io/measurement-portfolio/?scenario=certificate#demo)：匹配建议不替代人工确认。

**近期实践（2026-10-25）**：按计划组申报与证书历史查询、原始检测记录与车间台账分离，以及证书识别后的差异预览和人工确认。相关版本已交付测试站，OCR 仍有人工余项，新增功能的使用规模与收益尚未确认。[查看最新实践](https://mrperfume.github.io/measurement-portfolio/#recent-practice)。

业务规则与具体测试可在[工程证据](https://github.com/MrPerfume/measurement-portfolio/blob/main/docs/ENGINEERING_EVIDENCE.md)核实。公开原型使用合成数据与内存；完整系统案例另列验证层次，不代表生产收益或全面验收。
